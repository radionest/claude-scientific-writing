# Холодное чтение финального кандидата

## Что это

Чтение **точного финального кандидата** без истории drafting: объект, измерение, сравнение и
допустимый вывод восстанавливаются из самого текста. Это model-mediated review — проверка
читаемости аргумента, а не человеческая валидация и не проверка истины.

## Когда запускать

- Полный cold read — для содержательных секций (Введение, Методы, Результаты, Реферат/Аннотация,
  Заключение) и после deep-правок.
- Не для пунктуационных и однофразовых правок: там достаточно смежных предложений.

## Процедура

1. Читать только кандидата: без diff, без рассуждений редактора, без истории правок.
2. По каждой содержательной секции восстановить без подглядываний в другие разделы, если они
   не названы в тексте: **объект** (кого/что и на какой популяции), **измерение** (какая величина,
   каким методом), **сравнение** (с чем сопоставляется), **допустимый вывод** (что текст разрешает
   утверждать).
3. Для каждого существенного утверждения: где в документе его опора — «Результаты», «Методы»,
   таблица, источник? Утверждение без опоры в самом документе — находка.
4. Термины введены до первого использования; анафоры («это», «такой») разрешаются внутри документа.
5. Отчёт: вердикт по секциям + список «не восстанавливается: …» с местом в тексте.

## Инвалидация

Правка после cold read инвалидирует его: повторный cold read — только на новом точном кандидате.
Недоступные проверки — `not_run/unavailable`, не PASS.
