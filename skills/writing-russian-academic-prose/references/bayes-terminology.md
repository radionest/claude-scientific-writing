## Байесовская терминология — устоявшиеся русские эквиваленты

Машино проверяются правила `term-kredibilny-interval`, `term-koefficient-pravdopodobiya`, `term-bayes-factor` в `${CLAUDE_PLUGIN_ROOT}/canon/dictionary.json` — при расхождении **канон прав**. Таблица ниже — справочник для записи, не для линта: эквиваленты подтверждены русскоязычной медицинской литературой (Нурбаев и др., Сиб. журн. клин. экспер. мед., 2026; Корнеенков и др., Росс. оториноларингол., 2020; Димитриев и др., 2003).

| Английский термин | По-русски |
|---|---|
| Bayesian analysis / statistics | байесовский анализ / байесовская статистика |
| Bayes' theorem | теорема Байеса |
| prior (distribution) | априорное распределение (для событий — априорная вероятность) |
| posterior (distribution) | апостериорное распределение (апостериорная вероятность) |
| likelihood | функция правдоподобия |
| likelihood ratio | отношение правдоподобия |
| Bayes factor | фактор Байеса |
| credible interval | байесовский доверительный интервал |
| confidence interval (частотный) | доверительный интервал — без «байесовского» |
| posterior mean / median | апостериорное среднее / апостериорная медиана |
| MCMC | метод Монте-Карло с цепями Маркова |
| Metropolis–Hastings / Gibbs sampling | алгоритм Метрополиса—Гастингса / выборка по схеме Гиббса |
| conjugate prior | сопряжённое априорное распределение |
| hyperprior | гиперприорное распределение (гиперприор) |
| posterior predictive distribution | апостериорное предиктивное распределение |
| degree of belief | степень убеждённости |
| pre-test / post-test probability | предтестовая / посттестовая вероятность |
| information borrowing | заимствование информации (внешних данных) |
| probability of direction | вероятность направления эффекта |
| ROPE (region of practical equivalence) | область практической эквивалентности |
| highest density interval | интервал наибольшей плотности |
| maximum a posteriori (MAP) | оценка максимума апостериорного распределения |
| model evidence | маргинальное правдоподобие (реже «свидетельство») |

Ловушки, машинно не проверяемые — фиксируй в spec.md документа:
- credible ≠ confidence: «байесовский доверительный интервал» против частотного «доверительного интервала»; regex это не различит.
- odds в клинической литературе — «шансы», odds ratio — «отношение шансов».
- «байесовский множитель» (Bayes multiplier) — нишевый термин из диагностики тестов, с фактором Байеса не путать.
